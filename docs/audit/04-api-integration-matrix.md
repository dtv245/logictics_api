## Backend có nhưng frontend chưa tích hợp đầy đủ

- Optimization run API có đủ create/get/accept nhưng route UI chưa được mount.
- Fleet history policies/status events/mileage attributions và fleet report endpoints có backend; các pages/route constants chưa vào runtime router.
- `/api/roles` có controller và frontend API resource definition, nhưng không được thêm vào `appResources` runtime page set.
- Lark Base backfill/missing/sync admin endpoints và expense approval là backend capability chưa có UI quản trị tương xứng.

## Frontend có nhưng backend chưa hỗ trợ đầy đủ

- Documents upload/download (upload bị UI registry ẩn; download endpoint UI gọi không có controller route).
- Generic REST cho maintenance, HOS/ELD, DVIR, accidents, containers, load-board, products không có các collection controller tương ứng; runtime đang gate các module này.
- Map/tracking không có API nhận telemetry hoặc stream vị trí; dữ liệu là tọa độ đã persist ở Truck/load.
